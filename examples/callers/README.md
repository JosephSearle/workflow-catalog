# Caller examples

Copy-paste caller workflows for consumer repos. One file per public workflow, named the same as the workflow it calls.

`make new-workflow NAME=<name>` creates the file here from `templates/caller.yml`.

Workflow templates in a `.github` repo only show up in the "New workflow" picker for organizations. On a personal account these files fill that gap. If the catalog moves to an organization, publish them as workflow templates instead.

For pinning and Dependabot setup, see [docs/consuming.md](../../docs/consuming.md).
